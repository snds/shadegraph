## Packets

### T1 — WGSL parity for layer masks

- outcome: A layer with a `maskGraph` composites identically under the WGSL and GLSL ES backends; `output.mask` has a `wgsl` emitter; `chunk.raw` under WGSL emits one error diagnostic that says imported GLSL chunks are GLSL-only.
- context: ShadeGraph compiles one `ShaderDocument` to several targets and the toolbar lets the user pick WGSL. The WGSL `foldStack` skips `ShaderLayer.maskGraph` entirely (comment at src/compiler/backends/wgsl.ts:379), so masked layers silently render unmasked.
- findings: F-001
- acceptance: New tests in src/compiler/backends/wgsl.test.ts compile a two-layer document with a mask graph and assert the WGSL module multiplies the mask value into that layer's contribution; a `chunk.raw` node under WGSL yields exactly one error diagnostic; `pnpm typecheck` and `pnpm test` pass; GLSL snapshots unchanged.
- last verified state: ffcdd90
- non-goals: The `custom` blend mode fallback; WebGPU thumbnails (F-009); any change to glsl-es.ts or the document model.
- verification: `pnpm vitest run src/compiler/backends/wgsl.test.ts -t "mask" && pnpm test`
- rollback: discard the branch
- bail point: If mask compositing needs a model change (new field or schema shape), stop and report blocked.
- previous attempts: none
